# IMPORTANT (Windows + CUDA): install torch/torchaudio FIRST, from PyTorch's
# CUDA index, pinned to an exact version. If you `pip install` this file
# without doing that first, pip may pull a CPU-only torch build from PyPI
# and silently disable GPU acceleration. See README.md "Installation" for
# the exact commands and why this order matters.
#
#   pip install torch==2.11.0+cu128 torchaudio==2.11.0+cu128 --index-url https://download.pytorch.org/whl/cu128
#
# IMPORTANT: the PyPI release of chatterbox-tts (0.1.7, as of 2026-09) predates
# Multilingual V3 support (the `t3_model="v3"` parameter and the
# `t3_mtl23ls_v3.safetensors` checkpoint do not exist in that release — it only
# ships the v2 checkpoint). V3 exists only on the GitHub `master` branch. Since
# this project requires V3, chatterbox-tts is installed directly from source,
# not from PyPI. See README.md for the full explanation.
#
# `spacy-pkuseg` (a transitive dependency, used only for Chinese text
# segmentation) is intentionally NOT installed: it has no prebuilt wheel for
# this Python version on Windows and requires a C++ compiler to build from
# source. Chatterbox's own code wraps its import in try/except ImportError,
# so it degrades gracefully and is safe to omit for a French-only deployment.
# All of Chatterbox's other dependencies ARE installed normally below.
#
# Install order actually used (see README.md for full commands). Pinned to the exact
# commit verified against this project (rather than a floating @master) for

#   1. pip install torch==2.11.0+cu128 torchaudio==2.11.0+cu128 --index-url https://download.pytorch.org/whl/cu128
#   2. pip install -r requirements.txt
#   3. pip install "chatterbox-tts @ git+https://github.com/resemble-ai/chatterbox.git@5de7a54aa4e5e2baadb0182dde554908b48b85c2" --no-deps
